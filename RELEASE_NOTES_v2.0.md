# JobPilot Personal v2.0 — modern minimalist UI

iPhone-first visual refresh implemented with free native CSS and system typography. Changes: calm charcoal/indigo dark theme and softer light theme, redesigned metric cards, updated interview time cards, clearer calendar cells, cleaner job and review panels, accessible SVG navigation and a floating four-tab mobile dock. Preserves the existing Yahoo scanner, email review rules, application and calendar records, locally stored encryption key and all JavaScript business logic. No new dependencies or paid assets.

The connected Figma Starter plan reached its available MCP calls before the design canvas could be populated. Figma workspace: https://www.figma.com/design/SK8VO1GbpMZ2kZ6SCqIQUm. The working web UI was therefore implemented directly in the existing website code.

Checks: HTML element IDs preserved, mobile static layout rendered at 390px without horizontal overflow, CSS syntax verified, JavaScript syntax checked, 11 Yahoo parser regression tests passed. Does not activate Cloudflare push notifications.
