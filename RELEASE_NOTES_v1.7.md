# JobPilot v1.7 — Clean interview dashboard

The Home screen now shows only saved appointments. Emails with uncertain interview dates appear in Calendar / Review but do not appear in Upcoming interviews. Questionnaire and blocked-calendar subjects no longer display as interviews or automatic interview invitations. Existing pending legacy mail is still accessible in Review. A questionnaire can be added as a Deadline only after the user supplies the real deadline. We never assume its inferred 10:59 PM is an actual interview time. Existing jobs, calendar events, and Yahoo encryption key remain unchanged; cloud push remains unconfigured.

The change was locally tested with 21 scanner and browser checks, including the six-item screenshot scenario; live decrypted Yahoo data is not accessible to the assistant.
