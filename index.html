HOW TO GO LIVE

Connect Yahoo in 4 steps

  1. Publish this websiteUpload the files to a new public GitHub repository; enable Pages with GitHub Actions (not branch/root).
  2. Create a Yahoo app passwordYahoo Account Security → External connections → Create app password. Availability depends on Yahoo.
  3. Add 3 GitHub Actions secretsYAHOO_EMAIL, YAHOO_APP_PASSWORD, JOBPILOT_SYNC_KEY (the same 64-character key entered here).
  4. Run the scanner onceGitHub Actions → Scan Yahoo → Run workflow. Then return and tap Sync now.
